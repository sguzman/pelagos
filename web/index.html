Pelagos
🦀 Rust server · Pre-alpha

The open sea, under your control.

Pelagos is being built as a complete Rust replacement for Jellyfin Server with compatibility for unmodified Jellyfin clients, including Smart TVs.

⚙ Server

Native Rust HTTP listener and stable local server identity.

📺 Jellyfin compatibility

Not yet operational. TV connection and playback remain mandatory MVP acceptance tests.

🎞 Media engine

Library scanning, FFmpeg integration, transcoding and subtitles are planned.

🔐 Administration

Appearance control is live. Accounts and security-sensitive settings are not implemented.
