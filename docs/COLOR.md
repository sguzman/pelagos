# 🎨 Pelagos color

- **Identity:** clear ocean turquoise / open sea
- **Primary sRGB:** `#1DB2C0`
- **Perceptual specification:** `oklch(70% 0.115 205)`
- **OKLab:** approximately `L=0.70, a=-0.1042, b=-0.0486`
- **Swatch:** [assets/pelagos-color.svg](../assets/pelagos-color.svg)

The hue is maritime and distinct from typical Jellyfin branding. Color is specified perceptually (OKLCH) and mapped into the sRGB gamut. Foreground contrast is handled separately in the UI; a full screenshot/contrast/accessibility acceptance audit remains pending. GitHub repositories do not expose a native single project-color setting; the repo identity is expressed through its own swatch and documentation.
