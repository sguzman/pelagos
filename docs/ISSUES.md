# 📋 Project execution

Work directly on **main** unless explicitly directed otherwise. The accepted [progress ledger](progress.json) is the authoritative, machine-readable state; [roadmap](ROADMAP.md) is its human companion. Each milestone has a non-negotiable gate, each phase groups atomic acceptance tasks, and each task owns independent source, automated tests and real-client/production evidence checks. Never grant 100% on unverified scaffolds. Keep finished 100% tasks out of conversational progress reports.

MVP includes **all M0-M6 phases** and full Jellyfin v12.3 server parity with unmodified Smart TV apps. Early milestones are not reduced MVPs. GitHub issues may mirror tasks later, but the checked-in ledger remains durable even if issue automation is unavailable. All public changes must be neutral, professional, and exclude nonpublic user context.
